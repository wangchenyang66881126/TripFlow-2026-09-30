## 部署实施清单（待执行）

1. 服务器运行一个 FastAPI 进程，以 systemd 管理启动、重启；Nginx 同源转发网页和 API。前端沿用当前 Vite 构建产物，保持既有业务实现。
2. 使用独立的持久化数据目录和全新 SQLite 数据库，启动时生成公开预设。代码升级保留数据目录；不上传本机旧行程、账本、`.env`、依赖目录或本机日志。设置备份与恢复步骤，实际验证服务重启后预设 / 导出可用。
3. 前后端均启用预设模式；不配置 DeepSeek 密钥。公网请求只可使用公开预设涉及的接口，不能通过猜测 ID 读取私人历史行程，也不能创建真实生成任务。当前代码尚未完成这层公网入口限制，须在发布前落实与验证。
4. 当前预设属于面向所有访客的共同展示内容，不创建个人行程。本轮不引入账号系统；未来恢复真实生成前，必须完成后端用户隔离与鉴权，不能只切换演示开关。
5. 百度相关密钥仅通过服务器受保护的环境配置提供；按实际域名 / 出口 IP 调整百度控制台访问限制。验证地图脚本、地图瓦片、两天线路及酒店跳转。无云服务器实测前，不声明地图已在线验证。
6. 安装长图导出需要的 Chromium、系统依赖及中文字体；限制导出并发和 API 访问频率，避免少量内存被重复导出耗尽。日志避免记录查询参数、凭证和用户原文。
7. 公网只开放网页端口，后端 8000 端口只监听本机；管理端口限制来源。域名情况待确认，先用公网 IP 做技术连通验证，再配置正式分享地址和 HTTPS；IP 能打开不作为上线完成的依据。
8. 固定演示图片沿用现有来源说明；公开发布前核对素材授权，若需替换另行处理，不擅自删除现有功能或素材。
